# etf-radar · ETF/股票趋势雷达

每日晨报 + 盘中速报 + 周报的 A股 ETF/个股趋势预测管道，与 [ai-digest](../README.md) 同一套部署哲学：**纯 Python stdlib（零 pip 依赖）、1C/512MB 小 VPS 可跑、配置驱动、失败推飞书**。

## 功能

- **晨报（每交易日 8:30）**：昨日收盘复盘 + 今日预测——预测价 / ATR 区间 / 看涨概率，附**看涨看跌因子归因**（技术面贡献排序 + 高分新闻/公告），邮件 + 飞书推送
- **盘中速报（10/11/13/14/15 点）**：实时价 vs 当日预测区间，超上沿▲ / 破下沿▼即时标注
- **周报（周六 8:40）**：周涨跌、信号命中率、下周波动参考、本周 LLM token 总量
- **可问责设计**：预测全部入库、次日自动回填实际值，滚动 20 日胜率诚实展示（方向胜率≈50%、区间命中≈93%，回测基线随代码内置）
- **web 仪表盘**：口令保护（PBKDF2 + 登录限速 + 爆破告警），预测总览表 / 60 日走势 / 消息面情绪 / 信号复盘表 / 历史回测
- **token 台账**：每次 LLM 调用用量落盘，日报/周报自动汇总

## 数据与模型

| 层 | 来源 |
|---|---|
| 日K线 | 腾讯 fqkline（主，前复权）+ 新浪日K（兜底） |
| 实时价 | 腾讯 qt.gtimg.cn（主）+ 新浪 hq（兜底） |
| 消息面 | 东财公告 + 东财个股新闻 + Google News RSS |
| 情绪评分 | OpenAI 兼容 LLM 逐标的独立调用（-1~+1，公告给足幅度、软文克制） |
| 信号 | 动量0.40 / RSI 0.15 / 量能0.10 / MA20偏离0.05 / 消息面0.30；预测价=区间内按看涨概率定位 |

## 快速部署（三步）

```bash
# 1) 上传（key auth，与 ai-digest 相同模式）
SSH_TARGET=root@your-server bash deploy.sh /opt/etf-radar

# 2) 服务器上配置运行时（密钥只活在服务器）
cp config.env.example config.env   # 填 LLM_API_KEY / SMTP / 飞书webhook
python3 web.py init <web访问口令>

# 3) 安装定时与反代（systemd timer + Caddy 子域名）
bash remote-install.sh
```

改关注标的只需编辑 `common.py` 的 `WATCHLIST`（代码 / 名称 / 东财secid / 新闻查询词），`bash deploy.sh` 再推一次即可——管道逐标的幂等，中途加标的只补分析新标的。

> ⚠️ 输出为规则+消息面模型的统计结果，不构成任何投资建议；对外提供预测类内容请注意当地投顾合规。
